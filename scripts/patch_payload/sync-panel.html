Sinkronisasi Server (Internet)Kirim / ambil data langsung ke server Cek Blok. Yang menerima TIDAK perlu file manager — data digabung otomatis, duplikat dilewati.
Masuk pakai akun web (rekomendasi)
Username & password dibuat admin di web (menu Pengguna). Token perangkat dibuat otomatis saat login — data Kirim/Ambil langsung aktif.
Pakai token perangkat manual (opsional)
Token dibuat otomatis saat login, atau lewat web admin: menu Token Perangkat → Buat Token. 📚 Ambil Data Master = memperbarui daftar blok (estate, kebun, afdeling, luas, jumlah pokok) sesuai kebun akun Anda. Jalankan setiap kali admin memperbarui Data Master di web.
