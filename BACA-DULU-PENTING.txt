==========================================================
PAKET LENGKAP CEK BLOK — BACA DULU SEBELUM MULAI
==========================================================

Paket ini berisi SEMUA file proyek Cek Blok dalam 3 bagian.
Ukuran total ± 10 MB. Tidak perlu instal apa pun untuk
membuka paket ini.

----------------------------------------------------------
ISI PAKET
----------------------------------------------------------

1-SERVER-unggah-ke-GITHUB/
   cek-blok-server-github.zip
   = BACKEND + WEB APP (menyatu dalam satu file)
   Ini file yang diunggah ke repo GitHub Anda.
   Di dalamnya sudah termasuk:
   - Kode server (src/)          → web admin, API, login, /setup
   - Web app Cek Blok (public/app/) → versi patched dengan
     tombol "Kirim ke Server / Ambil dari Server"
   - Skema database (prisma/)
   - Tombol otomatis buat tabel (.github/workflows/)
   - 4 panduan lengkap (docs/) — yang paling detail:
     docs/PANDUAN-LENGKAP-PEMULA.md

2-APK-Android/
   Cek-Blok.apk
   = APLIKASI ANDROID Cek Blok (asli, ± 4,5 MB)
   Dipasang di HP petani/lapangan. Untuk mencatat transaksi
   secara offline (tanpa internet), lalu kirim data antar HP
   lewat berkas (Bluetooth / Quick Share) seperti biasa.

3-WEB-APP-salinan-terpisah/
   index.html + exceljs.min.js + pdf.min.js + dll.
   = SALINAN TERPISAH web app Cek Blok versi PATCHED
   PENTING: salinan ini SUDAH ADA DI DALAM paket server
   (bagian 1, di folder public/app/). Jadi Anda TIDAK perlu
   mengunggah folder ini ke mana pun. Fungsinya hanya:
   - cadangan (backup)
   - untuk pengembang yang ingin memasukkan patch ini ke
     proyek APK sendiri (ganti www/index.html lalu rebuild)

----------------------------------------------------------
ALUR KERJA YANG BENAR (urutannya)
----------------------------------------------------------

[1] Unggah "cek-blok-server-github.zip" ke repo GitHub
    (Panduan langkah demi langkah: docs/PANDUAN-LENGKAP-PEMULA.md
    di dalam ZIP server itu sendiri — buka lewat GitHub setelah
    terunggah)

[2] Ikuti panduan: Neon (database) -> Secret -> tombol Actions
    -> Vercel (deploy) -> buka /setup (buat admin) -> /login

[3] Setelah server hidup di https://alamat-anda.vercel.app :
    - Web app patched bisa dibuka di
      https://alamat-anda.vercel.app/app/
    - Di web admin: menu "Token Perangkat" -> Buat Token
    - Di HP: buka /app/ -> menu Riwayat -> Data Report ->
      "Server & Token" -> isi alamat server + token (sekali saja)

[4] Pasang Cek-Blok.apk di HP lapangan untuk pencatatan offline
    (atau langsung pakai web app di browser HP)

----------------------------------------------------------
ALUR KIRIM-TERIMA DATA BARU (tanpa file manager)
----------------------------------------------------------

HP pengirim                      HP penerima
"Kirim ke Server"  ->  SERVER  ->  "Ambil dari Server"
                                    data langsung tergabung,
                                    duplikat otomatis dilewati,
                                    TANPA file manager ✔

----------------------------------------------------------
CATATAN PENTING
----------------------------------------------------------
- Semua layanan gratis: GitHub + Neon + Vercel (tanpa kartu kredit)
- Simpan baik-baik: password GitHub, connection string database,
  JWT_SECRET, dan password admin
- Kalau bingung di langkah mana pun, buka
  docs/PANDUAN-LENGKAP-PEMULA.md bagian "Troubleshooting"
  (12 masalah paling umum + solusinya)
